# CSC110 Learning by Crafting – Thanh Luong

## Homework: Lists (Weekly Spending Tracker)

Students get a list of 7 numbers showing how much a person spent each day for one week. They write four functions that use the list to print a summary of the week: the total, the average per day, the highest-spending day, and how many days went over a budget the user types in.

### Learning outcomes
1. Students will be able to **write** a function that uses a loop to go through a list and calculate a total and an average.
2. Students will be able to **trace** through a list by index to find the largest value and the position where it appears, without using built-in functions like `max()`.

### Files
- `Luong_HW.py`: starter code for students
- `Luong_HW_solution.py`: example solution

### How to run
Open `Luong_HW_solution.py` in Thonny and click **Run** (or press F5). Type a daily budget when asked, such as `15`.

Or, in a terminal:
```
python Luong_HW_solution.py
```

## In-class activity: Functions (print vs. return)

### Mistakes this activity addresses
1. Thinking `print` and `return` do the same thing.
2. Forgetting to save a function's returned value (for example, calling `add_shipping(price)` instead of writing `price = add_shipping(price)`).
